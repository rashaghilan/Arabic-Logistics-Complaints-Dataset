# Arabic Logistics Complaints Dataset

This dataset contains 420 unique Arabic logistics complaints classified into seven complaint categories and six company types.

## Complaint Categories

- Delay
- Poor Service
- Inquiry
- Loss
- Financial Issues
- Regulatory Violations
- Other

## Company Types

- Shipping Companies
- Delivery Companies
- Transport Vehicle Services
- Rental Services
- Government Logistics Platforms
- Unspecified

The complaints were selected from the **Arabic Saudi Tweets for Governmental Reports** dataset published by L. Alhazmi on Kaggle. The logistics-related records were filtered, reviewed, and manually annotated as part of our study. The annotated dataset is shared with permission from the original dataset provider.

## Files

- `Arabic Logistics Complaints Dataset.csv`
- `Arabic Logistics Complaints Dataset.xlsx`

Both files contain the original complaint text, complaint label, and company type. The preprocessing used for model training is not applied to these files.

## Source

L. Alhazmi, “Arabic Saudi Tweets for Governmental Reports,” Kaggle, Dataset. Available: https://www.kaggle.com/datasets/lamakhalilalhazmi/arabic-saudi-tweets-for-governmental-reports.
